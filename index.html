The skill

Design, build and ship complete web applications.

Web Technologies covers the design, development, production and maintenance of websites and web applications. A web developer turns a client's requirements into a specification, designs the interface, builds the front end and the back end, integrates third-party platforms, then tests and deploys the result.

It is a single-competitor skill. Over the competition days each competitor works alone through a series of modules, under time limits, on a project they see for the first time.

Competition format

One competitor, several modules, a fixed clock.

Each module is a self-contained task with its own brief and time limit. Modules are marked against a marking scheme that follows the weightings of the Occupational Standard. The modules below are typical of recent Skill 17 competitions; the exact set for each competition is defined in its Technical Description and Test Project.

EuroSkills and WorldSkills alternate: EuroSkills one year, WorldSkills the next. At EuroSkills the skill is called Web Development.

Occupational Standard

Where the marks come from.

The WorldSkills Occupational Standard (WSOS) splits the skill into five sections, each weighted by its share of the total marks. It is the best guide to what to train. Weightings from the WorldSkills Lyon 2024 WSOS.

  • Section 15%

    Work organization and management

    Planning to deadlines, troubleshooting, research, deployment optimisation and version control with git.

  • Section 25%

    Communication and interpersonal skills

    Reading specifications and provided code, wireframes and flowcharts, matching client requirements.

  • Section 325%

    Design implementation

    Responsive, accessible interfaces to W3C and WCAG standards, typography, images, CSS animation and SEO.

  • Section 425%

    Front-End Development

    Modular JavaScript, libraries and frameworks, automated testing, debugging and deploying from the Linux CLI.

  • Section 540%

    Back-End Development

    Object-oriented PHP and/or Node.js, database design, MVC, APIs, web application security and server configuration.
