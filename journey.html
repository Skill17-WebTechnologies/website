Structure and style

Semantic HTML and modern CSS layout. Everything else in the competition is built on this.

Trains WSOS
  • 3 Design implementation
  • 1 Work organization
Tools HTML, CSS, Flexbox, Grid, a code editor, browser dev tools
Start here
  • MDN: Learn web development
  • W3C Markup Validator

Goals

  • Build a multi-page site using semantic HTML elements
  • Lay out a page with CSS Grid and Flexbox
  • Make the layout responsive from 320px to wide screens
  • Validate HTML and CSS with zero errors

Design and accessibility

Read a brief, turn it into a design, and make it usable for everyone.

Trains WSOS
  • 3 Design implementation
  • 2 Communication
Tools A design tool (e.g. Figma or Penpot), WCAG, a screen reader
Start here
  • WCAG 2.2 quick reference
  • MDN: Accessibility
  • MITS: SkyDrop Marketing Website

Goals

  • Draw a wireframe and a style guide from a short brief
  • Implement a design from a mockup, matching type and spacing
  • Meet WCAG AA contrast and full keyboard navigation
  • Optimise images and choose the right formats
  • Add a CSS animation that respects reduced motion
